Overview

This project is an automatic plant watering system based on ESP32.
It monitors soil moisture, temperature, and humidity and controls a water valve or pump to keep the soil moisture at a defined target level.

The system uses a TFT display for real-time monitoring and allows simple configuration of watering parameters.

⸻

Main Features
	•	Automatic watering based on soil moisture
	•	ESP32 microcontroller
	•	TFT display interface
	•	Real-time monitoring of:
	•	Soil moisture
	•	Temperature
	•	Humidity
	•	Adjustable target moisture level
	•	MOSFET-controlled water valve or pump
	•	Clear visual status indicators on the display

⸻

Hardware

Main components used:
	•	ESP32 development board
	•	Soil moisture sensor
	•	SHT41 temperature & humidity sensor
	•	DS3231 RTC
	•	4.0” TFT display (ILI9488)
	•	MOSFET driver (AO3400)
	•	Water valve or pump
	•	24V power supply (for valves)

⸻

Display Information

The TFT display shows:
	•	Soil moisture percentage
	•	Temperature
	•	Humidity
	•	Target moisture level
	•	Valve status
	•	System status indicators
